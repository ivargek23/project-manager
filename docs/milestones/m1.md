## In progress (M3)

### Security – draft PR #60 (issue #23)
Done so far:
- Spring Security with a `SecurityFilterChain`, form login with a custom login page, logout, and BCrypt password hashing; CSRF protection left on
- Users loaded from the database through `AppUserDetailsService` and `AppUserPrincipal`
- Three roles with different capabilities: ADMIN, PROJECT_LEAD, MEMBER – described in a [permission matrix](https://github.com/ivargek23/project-manager/blob/feature/23-security/docs/security.md) that separates global rights from rights inside one project
- Thymeleaf security dialect in the navigation, a 403 page, HR/EN messages for login and errors
- Persistent language switching (`LocaleConfig`)
- A parametrized test that reads every cell of the permission matrix from a CSV file (28 cases) and expects either success or 403, against PostgreSQL in Testcontainers

Next:
- Method-level authorization on service methods (`@PreAuthorize` with a project-access check)
- REST API for Project → Task → Subtask with DTOs, pagination and ProblemDetail, documented with springdoc-openapi
- Dependency editor with cycle prevention, critical-path computation, and the AI notes-to-tasks feature behind its port with a stub
