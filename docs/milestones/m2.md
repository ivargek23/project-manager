## Persistence

- Flyway manages the schema and the seed data, Hibernate only validates it
- Seed data: demo users for every role, 8 projects, 46 tasks and a dependency graph on the Website Redesign project, so the critical path and the charts have real data to show
- Entities for all nine domain tables, mapped to the relations LO4 asks for:
  - one-to-many: Project → Task, Task → Subtask
  - many-to-many with an association entity carrying attributes: ProjectMember (allocation percent) and TaskDependency (type, lag days)
  - optional relation: Task.assignee, a task can be unassigned
- Relations are lazy; where a page needs the related data I load it on purpose, e.g. findWithLeadById with an entity graph
- Graph projections NodeView and EdgeView read only ids, estimates and edges, so the graph work later does not load whole entities
- Mapping test against real PostgreSQL with Testcontainers

## Screens

### Project CRUD – PR #58
- List with search, status filter and pagination; detail page with summary cards
- Form objects with Bean Validation, a custom @ValidDateRange validator and messages in Croatian and English
- POST-redirect-GET with flash messages
- Optimistic locking, so a stale form shows an error instead of overwriting someone else's change
- Domain exception InvalidLeadException when the chosen lead can't lead projects
- Native <dialog> for delete confirmation, card layout below 640 px, 404 and error pages

### Task and subtask CRUD – PR #59
- Create, edit and delete tasks; subtasks are managed on the task edit page
- Assignee limited to project members (InvalidAssigneeException)
- MapStruct mappers between forms, commands and entities
